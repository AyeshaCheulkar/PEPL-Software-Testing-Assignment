
# BUG-001: Incorrect Backspace Character Handling During Serialization

## Severity
Medium

## Component
toml 0.10.2 - String Encoder

## File
toml/encoder.py

## Description
The TOML encoder incorrectly handles strings containing the backspace control character (U+0008).

It produces an IndexError for some inputs and corrupts string data for other inputs.

## Steps to Reproduce

### Case 1: Serialization Crash

Run:

```python
import toml

toml.dumps({"A": ["\x08"]})
```

**Actual Result:**

```text
IndexError: list index out of range
```

### Case 2: Data Corruption

Run:

```python
import toml

data = {"A": ["0\x08"]}
toml_text = toml.dumps(data)
result = toml.loads(toml_text)

print(toml_text)
print(result)
```

**Actual Result:**

The generated TOML contains:

```toml
A = [ "0x08",]
```

The parsed result is:

```python
{'A': ['0x08']}
```

The original backspace character is replaced by the literal characters `x08`.

## Expected Result

The encoder should produce valid TOML that preserves the original backspace character.

For example:

```toml
A = ["\b"]
```

After parsing, the original value should be preserved:

```python
{'A': ['\x08']}
```

## Actual Result

1. A string containing only the backspace character causes an IndexError.
2. A string containing a character before the backspace is incorrectly serialized, resulting in data corruption.

## Evidence

- Hypothesis discovered both failing inputs.
- `encoder.py` line 113 raises IndexError in Case 1.
- Case 2 generates `A = [ "0x08",]`.
- Python's standard-library `tomllib` correctly parses the valid TOML escape `\b` as the backspace character.

## Suspected Root Cause

The string escaping logic in `toml/encoder.py`, particularly the processing around lines 98–113, incorrectly handles the hexadecimal representation of control characters.

The logic splits the string around hexadecimal escape sequences and attempts to reconstruct them. This processing fails for certain backspace-containing strings.

## Impact

Applications using toml 0.10.2 may experience unexpected serialization crashes or silent configuration data corruption.

## Minimal Reproductions

### Case 1: IndexError

```python
import toml
toml.dumps({"A": ["\x08"]})
```

### Case 2: Data Corruption

```python
import toml
assert toml.loads(toml.dumps({"A": ["0\x08"]})) == {"A": ["0\x08"]}
```

Hypothesis automatically reduced the failing inputs to the minimal examples shown above.
