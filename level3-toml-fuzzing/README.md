# Level 3: Differential Fuzzing of TOML Parsers

## Project Overview

This project implements a differential fuzzing framework to identify inconsistencies and defects in the Python TOML library `toml==0.10.2`.

The project compares the behaviour of the third-party `toml` library against Python's standard-library `tomllib` parser using property-based testing with Hypothesis and pytest.

The objective is to discover serialization and parsing defects, automatically minimize failing inputs, document root causes, and propose fixes with regression tests.

## Technology Stack

- Python 3.11+
- toml 0.10.2
- tomllib (Python standard library)
- pytest
- Hypothesis

## Testing Objectives

### Property 1: Round-Trip Testing

Verify that data remains unchanged after serialization and deserialization.

`toml.loads(toml.dumps(data)) == data`

### Property 2: Serialization Compatibility

Verify that TOML generated by `toml.dumps()` is valid and can be parsed by Python's `tomllib` without changing the original data.

### Property 3: Differential Parsing

Compare `toml.loads()` and `tomllib.loads()` using generated TOML documents.

Both parsers should:
- Accept the document and return equivalent results, or
- Reject the document.

### Property-Based Testing

Hypothesis generates test inputs and automatically shrinks failing examples to smaller reproductions.

This helps identify minimal inputs that expose parser and encoder defects.

## Bugs Identified

### BUG-001: Backspace String Serialization

The encoder incorrectly handles strings containing the backspace control character (`U+0008`).

Observed behaviours:
- Serialization raises `IndexError`.
- Certain strings are incorrectly serialized, causing data corruption.

Proposed fix: Replace the original string-escaping implementation in the copied encoder with JSON-based string escaping and additional DEL-character handling.

### BUG-002: Incomplete Array Accepted

The decoder accepts malformed arrays without a closing square bracket.

Example:

```toml
A = [1,
```

Proposed fix: Validate array boundaries before processing array contents.

### BUG-003: Incomplete Inline Table Accepted

The decoder accepts an inline table without a closing brace.

Example:

```toml
A = {
```

Proposed fix: Validate the closing brace before parsing the inline table.

## Proposed Fixes

The original installed `toml` package remains unchanged.

Modified copies of the encoder and decoder are maintained separately under `fixes/toml/`.

The proposed fixes are tested independently through regression tests in `tests/test_bug_fixes.py`.

## Running the Tests

### Original Package: Verify Known Bugs

Make sure `PYTHONPATH` is not set to the fixes directory:

```powershell
Remove-Item Env:PYTHONPATH -ErrorAction SilentlyContinue
```

Run:

```powershell
pytest tests/test_known_bugs.py -v
```

Expected result: Four expected failures (`XFAIL`), representing the original bug reproductions.

### Patched Package: Run Regression Tests

Set the Python import path to the copied package:

```powershell
$env:PYTHONPATH = "$PWD\fixes"
```

Run the proposed fix tests:

```powershell
pytest tests/test_bug_fixes.py -v
```

### Run the Complete Patched Test Suite

```powershell
pytest -v --ignore=tests/test_known_bugs.py
```

The known-bug tests are excluded here because they are intentionally marked as expected failures against the original implementation.
